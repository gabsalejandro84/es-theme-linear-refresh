# My Custom RetroBat Theme (16:9 Widescreen)

A clean, modern, and highly customizable theme built for **RetroBat** (EmulationStation engine). This theme features completely custom, high-fidelity vector assets and smooth layout integration.

## 🚀 Key Features

* **Custom Vector Iconsets:** Includes 100% original, handcrafted SVG icons for multiple control layouts:
  * Xbox (Standard & Full Color Layouts)
  * PlayStation (Standard & Legacy Formats)
  * Nintendo Switch
* **Multiple Color Themes:** Built-in support for Dark, Oled, Light, and Blue colorsets.
* **Optimized Layout:** Designed specifically for stable **16:9 Widescreen** monitors with high-quality fonts and auto-scrolling game descriptions.

## 🛠️ Installation

1. Download or clone this repository.
2. Copy the theme folder.
3. Paste it inside your RetroBat directory at:
   `..\RetroBat\emulationstation\.emulationstation\themes\`
4. Open RetroBat, go to **UI Settings** -> **Theme Set**, and select this theme.

## ⚙️ Theme Options (UI Menu)

You can customize the experience directly from the RetroBat menu:
* **Help Icons:** Switch between Xbox, Xbox Color, PlayStation, PlayStation Legacy, or Switch controller vectors.
* **Color Theme:** Pick your favorite style (Dark / Oled / Light / Blue).
* **Description Speed:** Adjust how fast game descriptions text scrolls (Normal / Slow / Fast).
* **Visible Systems:** Choose between 3 or 5 active console logos visible in the main carousel.

---
*Note: This theme is currently optimized for 16:9 aspect ratios. Legacy 4:3 support is planned for future updates.*
